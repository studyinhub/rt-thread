## modbus

### 利用 pymodbus 测试 ascii ，主要是利用它来自动发送 ascii 数据

ASCII口：/dev/tty.wchusbserial14220
RTU 口：/dev/tty.wchusbserial142320

<!-- 创建一对虚拟串口 -->

sudo socat -d -d PTY,link=/tmp/ptyp0,raw,echo=0,ispeed=9600 PTY,link=/tmp/ttyp0,raw,echo=0,ospeed=9600

<!-- 用于替换 screen -->

sudo socat -,rawer,escape=0x0f /dev/tty.usbmodem123456781,clocal=1,nonblock=1,ispeed=115200,ospeed=115200

<!-- ser2tcp -->

nc -l 10001
sudo socat /dev/tty.usbmodem123456781,clocal=1,nonblock=1,cread=1,cs8,ixon=1,ixoff=1,ispeed=115200,ospeed=115200,raw,echo=0,crtscts=0 TCP4:localhost:10001

<!-- usb 转发到虚拟串口 -->

sudo socat -d -d /dev/tty.wchusbserial142320,clocal=1,nonblock=1,cread=1,cs8,ixon=1,ixoff=1,ispeed=9600,ospeed=9600,raw,echo=0,crtscts=0 PTY,link=/tmp/ptyp0
这样可以将一个串口的值转发到虚拟串口
这样我们利用 pymodbus 发送 ASCII 编码的数据帧到 /tmp/ptpy0 ,然后网关就收到了数据帧，
